# dynapi-contract

Pure request validation and presentation for `POST /v1/forecasts`, pinned to Python 3.12 / FastAPI 0.141.1 / Pydantic 2.13.4. No filesystem, network, clocks, threads, Tokio, Rayon, randomness or Python runtime. `cargo check --locked --target wasm32-unknown-unknown -p dynapi-contract --keep-going` verifies the portable crate independently of the native reader.

`validate_forecast(body, content_type)` returns `ValidationResult::Valid(ForecastBatch)` or `Invalid(Response { status, body })`. This is only body parsing and schema validation; routing, middleware, product lookup and query execution belong to later layers. Models retain raw variable strings. `output::normalize_variables` applies the handler's Python strip/dedupe/sort; `ForecastBatch::normalized()` provides the normalized model representation, with all defaults, aliases and normalized variables.

`json::Value` preserves insertion order, arbitrary-size integers, booleans and float64 values. Parsing duplicate object keys replaces the value without moving its position. `output::json(value, ensure_ascii)` writes compact JSON and rejects duplicate output keys and non-finite floats. Typed integer output has no decimal-digit limit; unlike default CPython, it accepts caller-constructed magnitudes above 4,300 digits (D4). Accepted requests cannot produce such values. Use `Value::data_float` only for data values Python maps to null; widen float32 before construction. Success bodies use `ensure_ascii=true`; error bodies use false. `ErrorEnvelope` handles string-detail responses; unknown products use Python repr of their id. Printability is pinned to Python 3.12's Unicode 15.0 table.

The Ryū/Python-layout float writer was integrated from the native formatter experiment. `cargo test -p dynapi-contract` checks explicit request/output examples, arithmetic expectations and parser safety without Python. [Fixture policy](tests/fixtures/README.md) describes the inputs and current coverage limits. See [DEVIATIONS.md](../../DEVIATIONS.md) for the fixed nesting guard, lone-surrogate domain, nonzero sub-minute datetime offsets and the wider typed integer-output domain. Maintainers verify migration output against the reference Python service outside this repository.
